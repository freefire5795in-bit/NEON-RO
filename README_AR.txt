NEON RP — ULTIMATE CINEMATIC PACK
==================================
- index.html: نسخة الموقع الحالية.
- effects-preview.html: صفحة معاينة مستقلة للتأثيرات الحركية (Canvas particles, glow, scanlines, interactive cards).
- assets/cinematic-backgrounds/: خلفيات سينمائية أصلية 4K.
- assets/effects/: طبقات طاقة/شرر شفافة عالية الدقة لاستخدامها في التصميمات.

مهم:
صفحة effects-preview.html هي معاينة مستقلة للتأثيرات وليست دمجًا تلقائيًا لكل التأثيرات في index.html.
لإظهارها افتح الملف محليًا بالمتصفح. دمج التأثيرات في الموقع الأساسي يحتاج تعديل index.html نفسه واختباره قبل النشر.
حجم الحزمة لا يساوي جودة أو سرعة الموقع؛ لا ترفع كل الأصول الكبيرة إلى GitHub Pages إلا إذا كنت تحتاجها.
